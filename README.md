# Vic-LRE
Codes for bioinformatic analysis and visualisation for manuscript "Genomics to understand the global landscape of linezolid resistance in Enterococcus faecium and Enterococcus faecalis".

# Bioinformatics
All codes used to run bioinformatic analyses are included in the analysis.Rmd script.

# Visualisation
All visualisation codes to generate figures in the manuscript are included in the visualisation.Rmd script.

# Directories
Paths to directories that contain input sequences on MDU PHL server.
